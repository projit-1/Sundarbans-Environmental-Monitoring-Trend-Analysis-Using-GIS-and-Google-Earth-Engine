# 🌿 Sundarbans Environmental Monitoring & Trend Analysis (2000–2025)

**A Data-Driven Environmental Monitoring Project Using Python, GIS, Google Earth Engine & Power BI**

## 📌 Project Overview

The Sundarbans, the world's largest mangrove forest, is an ecologically significant ecosystem facing various environmental pressures. This project aims to monitor and analyze long-term environmental trends in the Bangladesh Sundarbans using secondary environmental datasets, geospatial technologies, and data analytics.

Covering the period **2000–2025**, the project explores changes in key environmental indicators to identify historical patterns, long-term trends, and potential environmental concerns.

## 🎯 Objectives

- Analyze long-term rainfall and temperature patterns.
- Monitor vegetation conditions using NDVI and EVI.
- Explore salinity and coastal environmental trends.
- Assess changes in surface water, land cover, and shoreline.
- Identify monthly, seasonal, and annual environmental patterns.
- Develop interactive dashboards for environmental monitoring.

## 📊 Key Environmental Indicators

| Indicator | Analysis Focus |
|---|---|
| Rainfall | Monthly, seasonal & annual trends |
| Temperature | Long-term temperature variations |
| NDVI / EVI | Vegetation condition |
| Salinity | Salinity patterns and changes |
| Sea-Level-Related Data | Coastal environmental pressure |
| Surface Water | Water coverage changes |
| Land Cover | Land-use and land-cover changes |
| Shoreline | Shoreline dynamics |

## 🛠️ Tools & Technologies

- Google Earth Engine (GEE) – Environmental data extraction
- Python – Data processing and statistical analysis
- Pandas & NumPy – Data cleaning and manipulation
- Matplotlib – Exploratory data visualization
- GIS – Geospatial analysis
- Microsoft Excel – Dataset management and reporting
- Power BI – Interactive dashboards and visualization

## 🔬 Project Methodology

1. Data Collection: Collect historical environmental datasets from relevant satellite and scientific data sources.
2. Data Cleaning: Assess data quality, missing values, duplicates, invalid observations, and outliers.
3. Exploratory Data Analysis: Perform descriptive statistics, distribution analysis, seasonality assessment, and trend exploration.
4. Data Visualization: Develop interactive Power BI dashboards to communicate environmental patterns.
5. Statistical & Trend Analysis: Examine long-term changes and environmental variability.
6. Geospatial Analysis: Explore spatial patterns of environmental changes across the study area.
7. Reporting: Present key findings, limitations, and data-driven insights.

## ⚠️ Limitations

This project primarily relies on secondary environmental datasets and remotely sensed observations. Findings represent observed environmental patterns and statistical associations; they should not be interpreted as definitive evidence of causal relationships.
